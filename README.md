# IUB Computer Science Department Website

A fully responsive department website for the Department of Computer Science at Islamia University of Bahawalpur.

## 🚀 Live Demo
[https://iub-cs-department-website.vercel.app](https://iub-cs-department-website.vercel.app)

## 📋 Features
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop
- **Academic Programs**: Table with degree details and eligibility
- **Department Stats**: Student count, faculty, and research labs
- **Faculty Section**: HOD profile card
- **Campus Gallery**: Image showcase of labs and campus
- **Admission Process**: Step-by-step guide for applicants
- **FAQ Section**: Interactive collapsible questions
- **Contact Form**: With validation

## 🛠️ Technologies Used
- **HTML5**: Semantic markup and accessibility
- **CSS3**: Flexbox, Grid, custom styling, animations
- **Vanilla JavaScript**: For interactivity
- **Mobile-First Approach**: Clean UI/UX design

## 🎯 What I Learned
- Building responsive layouts with CSS Grid and Flexbox
- Implementing smooth scrolling and sticky navigation
- Creating accessible forms and tables
- Writing clean, maintainable, and reusable CSS
